# Epidemic Feedback

This repository is the place to report bugs, suggest features, and ask questions about Epidemic.

Epidemic adds configurable diseases, injuries, infection mechanics, remedies, thirst, and temperature effects to Minecraft survival servers. Optional integrations can connect Epidemic with plugins such as Domain, WorldGuard, PlaceholderAPI, and Myriad.

Source code: https://github.com/BronzWarq/epidemic

## Before opening an issue

- Search existing issues to see whether the problem or suggestion has already been reported.
- Use the Bug Report template for problems and the Feature Request template for suggestions.
- Keep one issue focused on one problem or request.

## Reporting a bug

Please include as much of the following information as possible:

- Epidemic version
- Minecraft and server software versions, including the Paper build
- Java version
- Relevant configuration sections for the affected disease, injury, remedy, thirst, temperature, or roleplay feature
- Versions of related plugins, and whether optional integrations are enabled
- Steps to reproduce the problem
- What you expected to happen and what happened instead
- Relevant server logs or error messages

For infection or symptom problems, describe the affected players and the actions or conditions that trigger the issue. For integration problems, include the relevant plugin versions and territory or clan settings.

## Suggesting a feature

Explain what you would like Epidemic to do, how it would improve survival gameplay, and any configuration options you think would be useful.

## Privacy

Remove passwords, access tokens, personal information, and private server details before posting logs or configuration. Do not upload complete server directories or unrelated files.
